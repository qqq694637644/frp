# XTCP QUIC Diagnostics

Optional diagnostics for this private frpc fork. It does not modify official frps 0.69.0, NAT punching, WARP SOCKS5, fixed UDP bindPort or ordinary application frames.

## Configuration

Add at the client TOML root, before proxy/visitor tables:

```toml
diagnostics.enabled = true
diagnostics.listenAddr = "127.0.0.1:9320"
diagnostics.token = "<domain-separated token generated by companion Python>"
```

Use port 9320 on mainland Windows and 9321 on the offshore VPS. x-ui generates the offshore fields when its Diagnostics switch is enabled. Generate the mainland token with the same `REVERSE_SOCKS_TOKEN`:

```powershell
python -m reverse_socks --print-diagnostics-config --frpc-diagnostics 127.0.0.1:9320
```

The token is `HMAC-SHA256(RSX3 shared secret, "rsx3-diagnostics-local-v1")`, lowercase hexadecimal. Both endpoints need the same token for authenticated raw QUIC/UDP tests. It is a real local API credential, not a public identifier.

The listener accepts only literal IPv4 loopback, a valid port, and a 32..512-byte token. An occupied diagnostics port is reported as a diagnostic failure; it never prevents normal frpc forwarding from starting. Keep the API private and never put it behind a public reverse proxy.

## Data collection

The qlog hook observes actual packet/ACK/loss/RTT events. It retains nullable metrics until observed; it does not fill missing measurements with zero. Original destination CID identifies the QUIC connection; Stream IDs are recorded against actual local bridge socket tuples. Tuple timestamps allow closed-session lookup without matching a reused port.

STREAM repeated byte offsets are counted independently from packet-loss declarations. Ranges are bounded (4096 streams / 128 disjoint ranges each). When capacity is exhausted, coverage becomes incomplete and the retransmission metric becomes unavailable. The common contiguous write path requires no extra range allocation.

Brutal publishes atomic once-per-second snapshots of target/max, calculated pacing rate, congestion window, unclamped sample ACK ratio and compensation ratio. These are configured/calculated values, not a substitute for observed packet rates.

UDP drops distinguish local peer mismatch, invalid/oversized app datagrams, path MTU, QUIC send errors and local delivery errors. No unreliable datagram is silently retransmitted over a reliable application stream.

## Active tests

Authenticated raw tests use separate QUIC unidirectional streams and a signed `FDQ1` header. The normal XTCP bidirectional streams still carry only their original local service data. One test is allowed per endpoint, with 1/10/50 MB and a 120-second deadline, SHA-256 integrity verification, and cancellation.

Diagnostic DATAGRAM echo uses reserved session ID zero, a random nonce, sequence number and HMAC. Normal RSX3 sessions never use ID zero. Replies are accepted only for pending authenticated probes, echo requests are bounded, and no public UDP socket is created. The test reports sent/received unique probes and receive-time RTT, not delayed queue-consumption timestamps.

## qlog recording

Private API `POST /v1/capture` accepts 30, 60 or 300 seconds. Capture works on existing connections, without restarting the tunnel. It stores native qlog event JSON in bounded memory (16 MiB/endpoint), uses a nonblocking recorder lock, and marks dropped events or size stops as incomplete. JSON-sequence exports keep original addresses and IDs. They do not recreate handshake events before capture started.

Existing `QLOGDIR` tracing is preserved as a separate upstream facility; it is not needed for the new bounded capture feature. Manually enabling unlimited native qlog output can still consume additional disk/CPU.

## API and safety

Bearer-authenticated loopback API:

- GET `/v1/snapshot` (`?compact=1` for periodic metrics)
- GET `/v1/lookup?local=...&remote=...&at=RFC3339Nano`
- POST `/v1/benchmark`, `/v1/udp-probe`, `/v1/cancel-test`
- GET/POST/DELETE `/v1/capture`, GET `/v1/capture/data`

No endpoint executes commands, changes frpc configuration, or opens a direct public connection. The offshore WARP-only route remains independent of the Xray target-egress route.

## Tests

`go test ./pkg/diagnostics ./pkg/transport/xtcpbrutal ./pkg/config/v1/validation`

Tests include real QUIC connections in both directions, verified payloads, authenticated DATAGRAM echo, native qlog contents, nullable measurements, bounded state, HMAC/length rejection and socket identity correlation. The cross-repository workflow additionally runs stock frps 0.69.0 and two real frpc processes.
